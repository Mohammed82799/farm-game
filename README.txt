بناء APK مباشرة من GitHub (بدون برنامج على جهازك)
===================================================
هذا الملف يضع اللعبة داخل التطبيق نفسه، فلا يفتح موقع GitHub ولا يظهر شريط المتصفح، ويعمل دون إنترنت.

1) أنشئ مستودعاً جديداً على GitHub (Public أو Private كلاهما يصلح).
2) ارفع محتويات هذا المجلد: Add file > Upload files، ثم اختر: www (المجلد)، assets (المجلد)، package.json، capacitor.config.json، .gitignore
   ملاحظة: إن لم يظهر مجلد .github عند الرفع فتجاوزه، فنحن سنُنشئه في الخطوة التالية.
3) أنشئ ملف سير العمل: Add file > Create new file
   في خانة الاسم اكتب بالضبط:  .github/workflows/build-apk.yml
   وافتح الملف build-apk.yml المرفق هنا والصق كل محتواه ثم Commit changes.
4) اذهب إلى تبويب Actions. سيبدأ البناء تلقائياً (أو اختر Build APK ثم Run workflow). يستغرق نحو 5 إلى 8 دقائق.
5) عند ظهور علامة صح خضراء، افتح التشغيل ونزّل الملف من قسم Artifacts (اسمه wadi-alhasad-apk). فك الضغط لتجد app-debug.apk.
6) انقل app-debug.apk إلى الجوال وثبّته (فعّل التثبيت من مصادر غير معروفة إن طُلب).

لتحديث اللعبة لاحقاً: استبدل www/index.html في المستودع وسيُبنى APK جديد تلقائياً.
